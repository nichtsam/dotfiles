# Global rules

## Discussing

- Never refer back by number or shorthand. Name the thing again in words.

## Starting work

Starting a new chain of actions needs my explicit agreement. Steps inside a chain I already
approved don't.

- Non-trivial work: run the quality guardrails (checks, lint, format), then state which
  intentions the change fulfils. STOP. Commit on approval.

## Commit messages

- English only, even when the diff is zh locale copy.
- If the diff doesn't make the intention legible, propose a body and ask before committing.
